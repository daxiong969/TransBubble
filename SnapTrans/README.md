# 译拍通 SnapTrans — iPhone 截图翻译 App 使用文档

一款基于 **SwiftUI + Apple Vision(OCR) + DeepL/苹果系统翻译** 的截图翻译 App。
**严格流程**：点击悬浮球 / 快捷指令触发 → 截图一次 → OCR 识别 → 缓存判断 → 翻译，不做实时持续录屏翻译。无登录、无广告、无埋点、不上传截图。

---

## 一、iOS 限制说明（必读）

- **iOS 没有安卓的全局悬浮窗权限**，普通 App 无法悬浮在其他 App 之上。本 App 采用 **画中画 PiP（Picture in Picture）** 方案：开启悬浮球后，一个可悬浮于任意 App 之上的小窗口作为触发按钮，点击即触发单次截图翻译。
- 点击 PiP 窗口时系统可能先回到 App，译文预览页会自动弹出，这是系统行为限制，属正常现象。
- **屏幕画面获取**依赖系统「屏幕录制」权限（ReplayKit 单帧截取），触发瞬间只截取一张画面，不会持续录屏、不会后台长时录制。

## 二、权限开启步骤

1. **屏幕录制**：首次触发时系统弹窗 → 选择「允许」；或到 设置 → 控制中心 → 添加「屏幕录制」。
2. **相册权限**：仅在导出合成图片时触发「仅添加」授权，可自主选择。

## 三、DeepL API Key 申请教程

1. 打开 https://www.deepl.com/pro-api → 注册 **Free 免费计划**（每月 50 万字符额度）。
2. 登录后进入 Account → Authentication Key，复制密钥（**以 `:fx` 结尾的是免费密钥**）。
3. 打开 译拍通 → 设置 → DeepL API Key → 粘贴 → 保存（Keychain 加密存储）。
4. 超出免费额度需升级 Pro 或换用「苹果系统翻译」引擎（免费，无需密钥）。

## 四、缓存机制说明

- 缓存 key = **原文 + 源语言 + 目标语言 + 翻译服务商**（MD5 存储，SwiftData 持久化）。
- 命中缓存直接渲染，不调用翻译 API，节省额度；**DeepL 与苹果翻译独立缓存**。
- 过期策略：永久 / 7 天 / 30 天（设置 → 缓存）；支持手动清空全部缓存。
- 无网络时：OCR 正常（本地）、缓存命中则显示译文、苹果翻译离线包可用时正常出译文、DeepL 提示网络错误。

## 五、苹果系统翻译（离线）

- 需要 **iOS 17.4+**；离线包下载指引：设置 → 通用 → 翻译 → 下载所需语言离线包（如英语⇄简体中文）。
- 离线包可用时翻译完全本地完成，不走外网；未下载会提示"离线翻译包未下载"。

## 六、TTS 朗读说明

- 预览页「朗读」菜单：朗读全部原文 / 译文、暂停 / 继续 / 停止；长按任意文字块可单独朗读。
- 设置 → 朗读（TTS）：语速调节、语音切换（中/英/日/韩系统语音）、自动朗读开关。
- 朗读时当前段落有橙色高亮标记。

## 七、深色模式

- 跟随系统自动切换，或设置 → 主题 手动强制浅色/深色。
- 译文样式有**浅色/深色两套独立预设**（字号、文字色、背景色、背景透明度均可自定义），对比面板对两个翻译源用蓝/绿区分。

## 八、翻译对比模式

- 预览页点「对比」开启：**左右分栏**并列展示 DeepL 译文 + 苹果译文，两个翻译源独立加载状态、独立缓存。
- 导出对比图：导出菜单 →「保存对比图（左 DeepL 右苹果）」。

## 九、快捷指令 + 辅助触控（小白点）配置教程

1. **创建快捷指令**：系统「快捷指令」App → 新建 → 添加动作「一键截图翻译」（译拍通）→ 命名保存。
2. **绑定小白点**：设置 → 辅助功能 → 触控 → 辅助触控 → 打开 → 自定义顶层菜单 → 添加图标 → 选择「快捷指令」→ 选「一键截图翻译」。
3. 也可绑定 Siri（说"截图翻译"）或「轻点背面」触发。
4. 触发逻辑与悬浮球一致（单次截图，不持续录屏）。若无法触发：检查 设置 →「允许快捷指令/小白点外部触发翻译」开关。

## 十、常见报错排查

| 报错 | 原因与解决 |
|---|---|
| 截图失败 | 未授权屏幕录制：设置 → 控制中心添加「屏幕录制」并允许 |
| DeepL 密钥错误(401/403) | 密钥复制不完整或已失效，重新粘贴完整密钥 |
| 配额耗尽(456) | 免费 50 万字符用完，升级 Pro 或换苹果翻译引擎 |
| 接口限流(429) | 请求过频，稍等重试（App 已内置自动重试一次） |
| 网络超时 | 检查网络；设置中可调超时秒数 |
| PiP 无法显示 | 确认系统支持画中画；主页面先开启悬浮球；切换前台 App 等待几秒 |
| 苹果离线包缺失 | 设置 → 通用 → 翻译 下载对应语言离线包；或换用 DeepL |
| 未识别到文字 | 切换 OCR 识别语种（设置 → OCR） |
| 快捷指令无法触发 | 打开设置页「允许外部触发」开关；重新添加快捷指令 |

## 十一、功能操作指引

- **手动框选识别**：预览页「框选」→ 拖动黄色矩形选中区域 →「只翻译选中区域」。
- **修改原文**：长按文字块 →「重新识别（修改原文）」→ 编辑后自动重译。
- **单块操作**：长按任意文字块 → 复制原文/译文、朗读原文/译文、隐藏/忽略该块。
- **导出图片**：预览页「导出」→ 合成图 / 原始截图 / 左右分栏对比图。
- **导出 TXT**：历史详情 → 菜单 → 导出 TXT（可选双源对比）。
- **收藏**：历史详情 → 菜单 → 收藏；主页「收藏」入口单独分类查看。
- **批量删除**：历史页右上「批量删除」进入编辑模式。
- **一键重译**：预览页右上「重新翻译」或「切换引擎」菜单。

## 十二、隐私承诺

无登录、无广告、无埋点、不收集任何用户行为数据。截图与历史全部存于本机（SwiftData）；仅 OCR 提取后的纯文本发送给 DeepL；密钥存于系统 Keychain；苹果翻译离线可用时不走外网。
